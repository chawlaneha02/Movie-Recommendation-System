Movie Recommendation System

A machine learning-based Movie Recommendation System that recommends movies to users based on their interests and movie preferences. The system analyzes movie features and finds similar movies to provide relevant recommendations.

Technologies

* Python
* Pandas & NumPy
* Scikit-learn
* Machine Learning
* Streamlit

Features

* Movie search and selection
* Similar movie recommendations
* Simple and user-friendly interface
* Fast and relevant suggestions

Developed for educational purposes.
